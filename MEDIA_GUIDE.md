# Media Setup Guide

To complete your portfolio setup, you need to add your image and video files to the `public` folder.

## Directory Structure
Please create the following folders inside `public/`:

1. `public/portfolio/` (For client feed images)
2. `public/reels/` (For video files)

## Required Files

### Client Images
Place images in `public/portfolio/` with the following filenames (JPG or PNG):

- `burjolevelup.jpg`
- `burjoibukota.jpg`
- `warmindo88.jpg`
- `pray-semarang.jpg`
- `d-sagara.jpg`
- `purawkawan.jpg`

*Note: Vertical aspect ratio (4:5) is recommended for feed aesthetics.*

### Video
Place your spotlight reel video in `public/reels/`:

- `spotlight.mp4`

*Note: Use MP4 format, compressed for web (H.264), preferably under 10MB for smooth playback.*

### Verification
Once files are placed, restart the development server or rebuild the site to see them appear.
